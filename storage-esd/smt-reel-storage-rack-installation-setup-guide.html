Seamless Installation & Setup

Follow our straightforward guide to get your SMT Intelligent Reel Storage Rack system up and running quickly and efficiently.

Installation in 3 Simple Steps

1

Server & VM Setup

Begin by setting up the server. Our system runs efficiently on a virtual machine. We provide a pre-configured VM image, making installation as simple as importing the file into VirtualBox or your preferred platform and configuring the network settings.

2

Rack Configuration

Connect the physical rack to your network via WiFi or Ethernet. Access the rack's web-based configuration panel to set its network IP and link it to the server address. The intuitive interface makes network setup quick and hassle-free.

3

Software & PDA Setup

Install the management software on your PC and the app on your PDA. A simple configuration file edit points the software to your server. Log in with the default credentials, and you're ready to start managing users, materials, and warehouse operations.
