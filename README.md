## 页面约定

- **单文件交付**：一个页面 = 一个 `.html`，无外部本地依赖；品牌资源走 `ph.smthelp.com` / `file.autoinsertion.com` 稳定 URL。

- **客户资料转公开页必须匿名化**：客户名、联系人、地址、单号、金额、报价条款一律不得出现；页面需自行说明引用出处与不确定性（未点名客户 / 规格需复核）。
